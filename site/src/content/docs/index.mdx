## Install

Each package is independent — install only what you need:

```sh
npm install @simplysf/simply-core
npm install @simplysf/simply-aep-core
npm install @simplysf/simply-apex-core
npm install @simplysf/simply-document-core
npm install @simplysf/simply-report
```

## Related

These libraries are also what power [SimplySF's Salesforce CLI plugins](https://github.com/SimplySF/simply-plugins) — but they don't depend on the CLI framework, so nothing here requires it.
